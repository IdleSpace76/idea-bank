Тестовые модели Idea Bank

blue-cube.glb: синий куб.
little-robot.glb: робот из нескольких деталей.
textured-cube-single.gltf: куб с текстурой в одном файле.
textured-cube-folder/: glTF с отдельными mesh.bin и textures/checker.png.

Файлы загружаются обычной кнопкой медиа, папка через «Загрузить папку glTF».
Модели распространяются по лицензии MIT проекта.
