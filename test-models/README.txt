Тестовые модели Idea Bank

1. blue-cube.glb — синий объёмный куб. Загрузи через обычную кнопку медиа.
2. little-robot.glb — робот из нескольких деталей. Проверь вращение и масштаб.
3. textured-cube-single.gltf — куб с шахматной текстурой, всё в одном файле.
4. textured-cube-folder — glTF с отдельными mesh.bin и textures/checker.png. Выбери эту папку кнопкой «Загрузить папку glTF».

Для проверки ошибки можно выбрать только textured-cube.gltf без остальных файлов: приложение должно сообщить, что не хватает mesh.bin.

Проверь сохранение проекта, перезагрузку страницы, изменение размеров окна и скачивание модели.
Модели созданы для тестирования, их можно свободно использовать и изменять.
