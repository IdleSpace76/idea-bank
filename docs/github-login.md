# Вход через GitHub

Доступ к облачной библиотеке разрешён одному GitHub-аккаунту. Настройка GitHub App и переменных приведена в разделах 3–7 [руководства по развёртыванию](deployment.md).

## Режимы входа

| Режим | Назначение |
| --- | --- |
| `IDEA_BANK_AUTH_MODE=local` | Локальный запуск без аккаунта |
| `IDEA_BANK_AUTH_MODE=github` | Вход только владельцу, указанному в `IDEA_BANK_OWNER_ID` |

Для публичного сайта обязателен режим `github`. При неполных настройках этого режима библиотека остаётся закрытой.

## Сессия и локальные данные

Сессия действует до 7 дней. Выход завершает сессию, но не удаляет библиотеку из браузера. Смена `AUTH_SECRET` завершает прежние сессии.

Вход не шифрует локальные данные: они доступны человеку с доступом к тому же профилю браузера. Перенос между устройствами выполняется отдельно через синхронизацию.

## Ошибки входа

| Ошибка | Что проверить |
| --- | --- |
| «Вход не настроен» | Переменные авторизации и перезапуск сервера или Redeploy |
| `AccessDenied` | Числовое поле `id` GitHub-аккаунта в `IDEA_BANK_OWNER_ID` |
| Ошибка callback | Совпадение домена и пути `/api/auth/callback/github` в GitHub App и `AUTH_URL` |
| Ошибка авторизации GitHub App | Client ID и Client secret одной App, не App ID или PEM |
