# Вход через GitHub

[Русский](github-login.md) · [English](en/github-login.md)

Доступ к облачной библиотеке разрешён одному GitHub-аккаунту. Настройка GitHub App и переменных приведена в разделах 3–7 [руководства по развёртыванию](deployment.md).

## Режимы входа

| Режим | Назначение |
| --- | --- |
| `IDEA_BANK_AUTH_MODE=local` | Запуск без аккаунта, библиотека и вложения на диске |
| `IDEA_BANK_AUTH_MODE=github` | Вход владельца из `IDEA_BANK_OWNER_ID`; для облачной библиотеки нужны настройки B2 |

Для публичного сайта обязателен режим `github`. При неполных настройках этого режима библиотека остаётся закрытой.

Если режим не задан, используется `local`. Обычные команды `dev` и `start` читают переменные окружения, включая `.env.local`; `.env.example` служит только шаблоном. Размещение на Vercel само по себе не включает `github`.

Для проверки GitHub-входа на компьютере используйте `npm run dev`. Команды `npm run local` и `local:start`, а также `runIdeaBank.cmd` принудительно запускают дисковую локальную версию без входа. Её библиотека переносится на сайт через ZIP.

## Сессия и данные браузера

Сессия действует до 7 дней. Выход завершает сессию, но не удаляет кеш, черновики и очередь неотправленных изменений этого браузера. Смена `AUTH_SECRET` завершает прежние сессии.

Вход не шифрует данные браузера: они доступны человеку с доступом к тому же профилю. Подтверждённые облачные записи хранятся в B2; в браузере остаются кеш и неотправленные изменения. При открытом приложении они синхронизируются автоматически. При истечении сессии отправка приостанавливается до повторного входа; локальные изменения сохраняются.

## Вход агента через MCP

Необязательный облачный MCP использует ту же GitHub App, отдельный callback `/api/mcp/oauth/callback` и отдельные токены с правами чтения или записи. Вход в браузере сам по себе не даёт агенту доступ. Подключение подтверждает владелец. Регистрация клиента и проверка MCP-токена не обращаются к B2. [Подключение и отзыв доступа](mcp.md#подключение-облачной-библиотеки).

## Ошибки входа

| Ошибка | Что проверить |
| --- | --- |
| «Вход не настроен» | Переменные авторизации и перезапуск сервера или Redeploy |
| `AccessDenied` | Числовое поле `id` GitHub-аккаунта в `IDEA_BANK_OWNER_ID` |
| Ошибка callback | Совпадение домена и пути `/api/auth/callback/github` в GitHub App и `AUTH_URL` |
| Ошибка авторизации GitHub App | Client ID и Client secret одной App, не App ID или PEM |
