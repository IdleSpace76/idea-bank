# Перенос библиотеки в локальную версию

Локальная версия сохраняет данные в папке `data` внутри приложения. Прежняя библиотека браузера и облачный сайт остаются отдельными источниками. Перенос выполняется через ZIP.

## Если прежняя локальная версия ещё запущена

1. Сохраните редактируемые идеи. Незавершённые черновики в ZIP не входят.
2. В окне резервных копий нажмите **Экспортировать ZIP** и сохраните архив.
3. Остановите приложение и обновите исходники.
4. Выполните `npm ci`, затем `npm run local`. В Windows можно открыть `runIdeaBank.cmd`.
5. Откройте резервные копии, выберите **Импортировать ZIP** и подтвердите импорт.

## Если приложение уже обновлено

Откройте его в том же браузере и по тому же адресу, по которому работала прежняя версия. В окне резервных копий появится **Экспорт прежней библиотеки браузера**. Сохраните ZIP, затем импортируйте его обычной кнопкой **Импортировать ZIP**.

Экспорт читает сохранённые идеи и вложения, не меняя старую библиотеку. Черновики остаются в прежнем хранилище. Если вложение отсутствует, экспорт сообщит об этом и остановится.

Данные браузера привязаны к полному адресу. `http://127.0.0.1:3000` и `http://localhost:3000`, а также разные порты имеют отдельные хранилища. Штатный запуск сохраняет адрес `http://127.0.0.1:3000`. Если раньше использовался другой порт, запустите `npm run local -- --port 3001`, указав прежний номер. Если данные браузера уже удалены, потребуется ранее сохранённый ZIP или облачная копия.

## Перенос между локальной и облачной версиями

Экспортируйте ZIP в исходной версии и импортируйте его в нужной. Перед экспортом с облачного сайта дождитесь завершения синхронизации. Локальная версия не подключается к B2 и не отправляет данные на сайт автоматически.

ZIP облачной библиотеки создавайте на самом сайте. Кнопка экспорта прежней библиотеки браузера предназначена для старого локального хранилища; частичный кеш облачного сайта не заменяет полный архив.

Импорт объединяет библиотеки. Идеи, отсутствующие в ZIP, остаются на месте; совпадающие пропускаются. Для разных версий выберите текущую, архивную или обе. При сохранении обеих импортированная копия получает суффикс `imported`.

Для полной замены сначала сохраните резервную копию, затем подтвердите **Очистить голову** и импортируйте нужный ZIP. Очистка удаляет все идеи и разделы, включая Example.

## Перенос папки приложения

Остановите приложение и перенесите всю папку вместе с `data`. При стандартной настройке новое расположение выбирается автоматически. Если задан абсолютный `IDEA_BANK_DATA_DIR`, данные остаются по указанному пути. На другом компьютере или после смены версии Node.js выполните `npm ci`, чтобы установить подходящий драйвер SQLite.
